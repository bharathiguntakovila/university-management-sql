 EXERCISE 10: SELECT with LIKE - Search by Name Pattern

Question: Write a query to find all students whose name starts with 'A'.

EXERCISE 15: UPDATE with JOIN - Update Fee Amounts by Department
Question:  Update Fee Amount in Fees table based on Student's Department:

Computer Science (DeptID=1): Increase by 10%
Electronics (DeptID=2): Increase by 5%
Other departments: Increase by 2%
Answer:
select f.feeid,s.deptid,s.studentid,f.amount from students s
join fees f on f.studentid=s.studentid
where deptid not in (1,2)

EXERCISE 16: SELECT with INNER JOIN - Get Student Courses
Question :EXERCISE 16: SELECT with INNER JOIN - Get Student Courses
Answer: 
select st.studentid,s.name,c.coursename,st.grade from studentcourses st
join courses c on c.courseid=st.courseid
join students s on st.studentid=s.studentid
